A FEW GOOD DETAILS

A format that fits.

Excel, CSV or TSV. Start with an array of objects, or a single object for one row. Keys become columns in first-seen order. Missing values and null become blank cells; nested objects and arrays stay together as JSON text.

Keep your values intact. Spreadsheet cells are exported as text, preserving codes such as “001”. CSV and TSV values that could act as formulas receive a protective apostrophe.

Just need readable JSON? Formatted JSON accepts any valid JSON value, preserves its structure, and adds two-space indentation. Duplicate keys are rejected to avoid losing data.

Keep it manageable. Spreadsheet exports support up to 50,000 data rows, 100 columns, 200,000 cells including headers, and 32,767 characters per cell.
