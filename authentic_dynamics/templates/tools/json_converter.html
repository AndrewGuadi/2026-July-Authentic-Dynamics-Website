A FEW GOOD DETAILS

A format that fits.

Choose your Excel structure. Start with an array of objects, or a single object for one row. The recommended layout flattens objects and moves arrays to related sheets. Preview the sheet names, row counts and columns before downloading.

Keep the relationships. Generated @record_id and @parent_id columns link sheets; @index preserves array order starting at 0. Mixed arrays use @type and @value alongside object fields. Empty arrays show [] in the parent row. Arrays inside array items stay as JSON text.

Field names stay distinct. In expanded layouts, literal dots and backslashes in keys are escaped with a backslash. Keys starting with @ are escaped too, so they cannot overwrite generated columns. An empty key appears as \e.

Other table formats. Word, PDF, CSV and TSV remain single tables, with nested values as JSON text. Missing fields and null values become blank cells in tables.

Preview the actual PDF. Automatic layout compares portrait, landscape and column widths at your chosen text size. Every page is checked for text coverage and cell boundaries before export. The preview shows the generated PDF, with selectable text in the downloaded file.

Long text is welcome. PDF cells can exceed Excel’s 32,767-character limit. Wrap the full value or move values over 1,000 characters to an appendix. Unsupported characters and scripts that need shaping are shown as visible Unicode escape codes, with a notice.

PDF limits. Up to 12 selected columns, 5,000 rows, 2 million characters of rendered text, 200 pages, and 10 MiB of output. Narrow layouts may require fewer columns. For larger datasets, choose Excel or JSON.

Keep your values intact. Spreadsheet cells are exported as text, preserving codes such as “001”. CSV and TSV values that could act as formulas receive a protective apostrophe.

Just need readable text? Plain text and formatted JSON accept any valid JSON value, preserve its structure, and add two-space indentation. Duplicate keys are rejected to avoid losing data.

Keep it manageable. Excel supports up to 20 sheets, 50,000 data rows and 200,000 cells across the workbook, including generated columns and headers. Each sheet supports 100 columns; each cell supports 32,767 characters. Expand up to 10 nesting levels.
