Will my code expire?

The code directly contains your link. There is no Authentic Dynamics redirect, subscription, or scan limit. The destination website must remain available; third-party links can still expire or change.

Can I change the destination later?

A downloaded code cannot be edited. Generate and print a new code for a different URL. For a menu you update frequently, use a stable page on your own website and change the content of that page.

Do you track scans or store my design?

No. Your design stays in page memory until you close or refresh this tab. Your destination website may have its own analytics. We do not check or visit the destination unless you choose Test this link.

How do I make it easy to scan?

Keep the blank border, use a dark code on a light background, and leave logos outside the pattern. Try the printed size in its intended lighting and scanning distance. Longer URLs produce more intricate codes.
